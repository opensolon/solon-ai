## MCP Tool Discovery (4 tools in total)
### Mode: Server catalog
MCP tools are organized by server, and only the server catalog is listed below. Follow this flow:
- **Step 1 (Pick a server)**: Choose a server from the "MCP server catalog" by its description, then call `list_server_tools` (with server_name, optionally a keyword to filter) to see its tools, parameter signatures and usage notes.
- **Step 2 (Execute)**: Build the arguments from the signature and submit the execution with `call_tool` (with server_name, tool_name and tool_args). If the signature contains object, any or array, or ends with …, first check the full parameter schema with `get_tool_detail`.

> If the catalog does not tell you which server to use, search across servers by keywords with `search_tools` first instead of listing the tools of every server.
