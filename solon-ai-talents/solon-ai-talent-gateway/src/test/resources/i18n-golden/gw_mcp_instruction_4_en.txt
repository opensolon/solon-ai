## MCP Tool Discovery (4 tools in total)
### Mode: Search discovery
The MCP tool library is huge and the list is collapsed. Follow this flow:
- **Step 1 (Search)**: First use `search_tools` to find matching tools by keywords (results include server_name and tool_name).
- **Step 2 (Details)**: Call `get_tool_detail` (with server_name and tool_name) to get the parameter schema.
- **Step 3 (Execute)**: After confirming the arguments, submit the execution with `call_tool` (with server_name, tool_name and tool_args).

> **Note**: Do not guess tool names. Search by keywords, e.g. search_tools('weather')
