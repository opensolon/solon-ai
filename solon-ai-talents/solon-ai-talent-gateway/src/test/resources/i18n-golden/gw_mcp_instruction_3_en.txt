### Mode: Dynamic discovery (list)
The tool library is large, so only names are shown. Follow this flow:
- **Step 1 (Shortlist)**: Infer the function from the server and tool names in the "Tool list" below, or search with `search_tools`.
- **Step 2 (Details)**: Call `get_tool_detail` (with server_name and tool_name) to get the parameter schema.
- **Step 3 (Execute)**: After confirming the arguments, submit the execution with `call_tool` (with server_name, tool_name and tool_args).
