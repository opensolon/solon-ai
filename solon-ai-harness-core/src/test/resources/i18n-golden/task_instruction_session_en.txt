## Task Assignment Strategy:
1. **Prefer parallelism**: When a task can be split into independent units that do not interfere with each other (e.g., developing different modules, searching multiple sources), use `multitask` to save time.
2. **Atomicity**: Each subtask should have clear boundaries.
3. **Context awareness**: The prompt must contain all the background the task needs; subagents cannot see the full history of the main session.
